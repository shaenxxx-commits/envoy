# Field Run 002 — Kleros Field Reconnaissance

FIELD: KLEROS
STAGE: FIELD RECONNAISSANCE
STATUS: CLOSED

## Objective

Map the current Kleros field before forming a formal research hypothesis.

## Focus

- current architecture
- V1 / V2 transition
- real cases
- emerging structures
- claimed vs built vs observed
- unknowns

## External Result

The three independent External nodes converged on Kleros as a transitional architecture:

- V1 remains operational.
- V2 is being developed and deployed.
- V2 introduces modular dispute mechanisms.
- Arbitrum is an important V2 environment.
- Agentic Commerce Court represents an emerging agent-oriented layer.
- Atlas, Vea, dispute kits and other components form part of the developing architecture.

## Lead Interpretation

Kleros should be treated as a dynamic field rather than simply as an arbitration platform.

A potentially important research boundary was identified:

CLAIMED
→ DOCUMENTED
→ BUILT
→ INDIVIDUALLY OBSERVABLE
→ MACHINE-REPRODUCIBLE

This was NOT adopted as a formal hypothesis.

## Decision

Proceed to a reproducibility / sensor test before analysing field patterns.
