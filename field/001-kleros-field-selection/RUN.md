# Field Run 001 — Kleros Field Selection

FIELD: KLEROS
STAGE: FIELD SELECTION
STATUS: CLOSED

## Objective

Select the first active field for Envoy reconnaissance.

## Candidate Fields

- UDRP
- Specific types of domain disputes
- New TLD domain disputes
- Kleros / crypto arbitration

## Method

Independent External reconnaissance was used to compare:

- public trace
- source accessibility
- existing synthesis
- unresolved structural questions
- ability to test
- practical value

## Result

All three External nodes converged on:

1. UDRP
2. Kleros
3. New TLD disputes
4. Specific types

## Lead Interpretation

UDRP appeared more mature and easier to observe, but also more saturated.

Kleros appeared less synthesized, technically more difficult, and potentially more open as an emerging field.

Observation cost itself was treated as a field-selection variable.

## Decision

KLEROS selected as the active Envoy field.

UDRP remains a possible future field and was not rejected as a research object.

## Next Observation

Reconnaissance of the current Kleros architecture, trajectory and observable field.
