## LEAD INTERPRETATION

Run 025 changes the picture of the field in two
ways:

1. The two-template split (Lemon vs generic) does
   not correspond to operator identity. Both large
   operators run both templates in parallel. This
   suggests either coordination between the
   operators, or a shared backend that assigns
   templates based on case type rather than
   operator.

2. Half the corpus is now retail usage. This
   layer was 39% in Run 014 and 51% in Run 025.
   If the trend continues, the field transitions
   from "two enterprise clients" to "general public
   adoption through a public tool".

Neither fact changes the absolute scale (still
~0.5 disputes/day), but both change the question.
The field is not "one operator" and not "two
operators". It is a growing public utility with
two large anchors and a retail tail.

## Decision

The operator-template question is answered: no
one-to-one mapping. The field is layered.

Run 026 (temporal dynamics) is the right next step
to distinguish trend from spike.
