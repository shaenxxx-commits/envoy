## Слой E — СТРУКТУРНАЯ ГИПОТЕЗА

**`[МОЯ ПОЗИЦИЯ]`** Три уровня связи, разные по природе:

1. **Kleros ↔ Lemon** — коммерческая интеграция.
2. **Kleros ↔ Mendoza** — институциональный пилот,
   самая прочная.
3. **Kleros ↔ федеральное правительство** —
   идеологическое совпадение.

**`[ГИПОТЕЗА]`** Наиболее вероятный «подковёрный» узел —
**Mendoza**, не Буэнос-Айрес.

**`[ГИПОТЕЗА]`** Все три уровня могут быть частью
одной стратегии Ast — построить прецедент
в Аргентине через:
- корпоративную интеграцию (Lemon);
- государственный пилот (Mendoza);
- регуляторное признание (893/2025).
