# ENVOY

Envoy is a quiet field project.

It is deployed into a concrete real-world field for reconnaissance, method testing, practical discovery, and field research.

Envoy has two distinct but connected purposes:

1. Research — observe the field, test methods, identify structures, and accumulate verified knowledge.
2. Resource discovery — identify practical niches that may generate resources for the main projects.

These purposes must not be conflated.

Envoy is an independent project. It may use knowledge, methods, or public material from other projects, including NOVA CORTEX LAB and its Corpus, but those projects remain external sources.

Provenance must remain explicit:

LAB fact != Corpus representation != Envoy observation != Envoy interpretation != Envoy result.

The initial task of Envoy is not to prove a predefined thesis or to select a niche in advance.

The initial task is reconnaissance.
